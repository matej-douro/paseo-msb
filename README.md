# paseo-msb

A Paseo plugin that turns microsandbox microVMs into first-class Paseo hosts.

Create a VM from a form and it appears in the Paseo host picker like any other machine, with its own workspaces, agents, terminals, and diffs. The plugin is the control plane for those VMs; day to day work happens in Paseo's normal host UI.
